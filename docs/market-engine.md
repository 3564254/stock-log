# 시장 분석 엔진

미국 시장 전체의 국면을 판단합니다. 개별 종목 신호가 아니라 "지금 시장이 어떤 상태인가"를 봅니다.

## 흐름

```
지표 데이터 (FRED · 지수 ETF)
  → 분석기 11개가 각각 -100 ~ +100 점수
  → MarketRegimeEngine이 가중합으로 국면 판정
  → 화면 · AI 시황 브리핑
```

## 분석기

| 분석기 | 보는 것 | 가중치 |
|---|---|---|
| Trend | 지수가 이동평균 위에서 오르는지 | 15% |
| Risk | VIX · 하이일드 스프레드로 본 위험 선호 | 15% |
| Momentum | 최근 상승 속도와 가속 | 10% |
| Breadth | 소수 종목만 오르는지, 넓게 오르는지 | 10% |
| Rates | 금리 수준과 장단기 금리차 | 10% |
| Liquidity | 시중 자금 흐름 | 10% |
| Macro | 물가 · 고용 · 소비로 본 경기 국면 | 10% |
| Credit | 회사채 금리차, 금융 스트레스 | 10% |
| Sector | 공격 업종이 시장을 이끄는지 | 5% |
| Defensive | 필수소비재 · 금 · 달러로 피하는지 | 2.5% |
| CrossAsset | 주식 · 채권 · 원자재 방향 | 2.5% |

괴리 감지기(DivergenceDetector)는 지수는 오르는데 VIX도 오르는 경우 같은 엇갈림을 찾아 감점만 합니다.

## 판정

- **국면**: Trend 점수(±20)로 상승 · 하락 · 중립, Risk 점수(±20)로 위험 선호 · 회피를 나눠 조합합니다
- **급변**: 상승 추세인데 Momentum이나 Breadth가 -40 이하면 "단기 급락"으로 표시합니다
- **신뢰도**: 방향이 뚜렷한 지표들이 같은 쪽을 가리키는 정도(60%) + 점수 세기(40%). 괴리 경고가 있으면 깎습니다

가중치는 초기값이며 백테스트로 최적화하지 않았습니다.
