# 디자인 원칙

토스 같은 국내 핀테크 앱처럼, 숫자가 한눈에 읽히는 깨끗한 화면을 목표로 합니다.

## 색

| 용도 | 색 |
|---|---|
| 상승 · 이익 | 빨강 `#f04452` |
| 하락 · 손실 · 주요 버튼 | 파랑 `#3182f6` |
| 좋음 (가격과 무관한 상태) | 초록 `#05c072` |
| 주의 | 주황 `#f5a623` |
| 글자 | `#191f28` · 보조 `#4e5968` · 라벨 `#626c7a` |
| 바탕 | 회색 `#f2f4f6` 위에 흰 카드 |

- 빨강은 오름, 파랑은 내림. 국내 관례를 따르고 절대 뒤집지 않습니다
- 가격 방향이 아닌 상태(규칙 충족, 시장 상태)는 초록 · 회색 · 주황으로만 표시합니다
- 강조는 테두리 대신 옅은 바탕색으로 합니다

## 글자

- Pretendard 한 가지만 씁니다
- 숫자는 굵게(700~800), 고정폭 숫자(`tabular-nums`). 라벨은 작고 옅게
- 한국어 문장은 `word-break: keep-all`

## 모양

- 간격: 4 · 8 · 12 · 16 · 20 · 24px
- 모서리: 8~20px, 버튼은 알약 모양
- 버튼: 주요 동작 하나만 검정, 나머지는 회색
- 카드: 회색 바탕 위 흰 면, 테두리 없이 여백으로 구분

토큰 값은 `src/main/resources/static/css/tokens.css`에 있습니다.
